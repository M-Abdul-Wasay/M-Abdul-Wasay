## Selected Projects

### 3D Voxel Engine — C++, OpenGL
Built a Minecraft-style voxel engine from scratch: chunk-based infinite world streaming, ambient occlusion lighting, dynamic sky/water systems, raycasting for block interaction, and first-person movement with collision. No game engine — every system implemented directly.

### Custom Git Implementation — Python
Reimplemented Git's core internals without any external Git libraries: content-addressable object storage with zlib compression and SHA-1 hashing, a staging area engine, tag resolution, and commit-graph traversal for checkouts, including a safety guardrail that blocks unsafe checkouts exactly like real Git does.

### Local AI Assistant — Python
A fully local, low-latency AI assistant inspired by conversational AI systems: asynchronous backend architecture separating voice capture from database/UI logic, offline LLM inference via Ollama running under 250ms response time, and real-time hardware telemetry streamed into a live visualization layer. Runs entirely on consumer hardware.

### Custom Programming Language — Python
Designed and implemented an interpreted language from scratch: hand-written tokenizer, recursive-descent parser, and a call-stack-based interpreter supporting variables, functions with recursion, control flow, and user input — built to understand how language runtimes actually work, not to use one.

### Physics-Based Black Hole Renderer — Python
A general-relativity visualization modeling space-time curvature, the Schwarzschild radius, gravitational lensing, and relativistic Doppler shifts, translated directly from the underlying physics equations into a real-time rendering pipeline.

### Terminal Typing Test — JavaScript
A typing test that pulls live, real code snippets from GitHub repositories (Linux, React, Redis, Rust) instead of generic sentences, with comment-stripping and GitHub rate-limit fallback handling. Deployed as a web app.
